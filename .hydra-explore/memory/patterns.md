# Coding Patterns

- TypeScript project with tsconfig.json
- File-based routing in app/ directory
- Shared components in components/ directory
- Theme constants in constants\theme.ts
- Custom hooks in hooks/: use-color-scheme.ts, use-color-scheme.web.ts, use-hierarchical-back.ts, use-sleep-detection.ts, use-theme-color.ts
- Database layer in database/: activities.ts, cognitive-tests.ts, correlation-analysis.ts, daily-review.ts, database.ts
